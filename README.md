# YinnMotion

**Code-first Android video editor** by Yinndev / Ilham.

YinnMotion is being built as a lightweight native Android motion editor with a code-first workflow.

## Current foundation

- Kotlin + Jetpack Compose native UI
- Media3 ExoPlayer / Transformer dependencies
- HTML, CSS and JavaScript editing workspace
- Import media and audio through Android's system document picker
- Project identity and About screen
- GitHub Actions APK build

## Build

Open **Actions → Build YinnMotion APK → Run workflow**. Download the `YinnMotion-1.0.0-APK` artifact after the workflow completes.

## Current development status

This repository is the first app scaffold. The editor UI and import flow are present; real-time HTML/GSAP preview, timeline editing, audio mixing and MP4 rendering are still under development and are not yet represented as completed features.
